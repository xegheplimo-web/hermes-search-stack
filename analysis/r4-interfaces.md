## §2 Shared conventions

- Errors: raise `vn_geo.VnGeoError` with an actionable message. CLI: exit 0 ok, 1 runtime error, 2 usage.
- HTTP: `urllib.request` with header `User-Agent: hermes-vn-geo/0.1`, timeout param (default 30.0). Wrap HTTP/JSON errors into `VnGeoError`.
- CLI pattern per module: `python -m vn_geo.<module> <cmd> ...`; `main(argv: list[str] | None = None) -> int`; support `--json` on output commands; `if __name__ == "__main__": raise SystemExit(main())`.
- SearchStore integration — documents ONLY, no schema changes. Use:
  - `SearchStore(db_path)` → `.ingest_document(url, text, *, title=None, provider=None, fetched_at=None, format="markdown", meta=None) -> int` (dedup by `(url_key, sha256(text))`; new content for same url = NEW VERSION, append-only — this powers refresh/diff).
  - `.search(query, *, limit=10, mode="fts", snippet_len=200) -> list[dict]` → `{doc_id, url, title, provider, fetched_at, snippet, score, mode_used}`.
  - `.record_event(kind, payload) -> int`, `.stats() -> dict`, `.conn` for direct SQL when filtering by `meta`.
  - `documents_current` view = latest version per url_key; full `documents` table = all versions.
- Provider/format tags (freeze): `provinces-api`/`admin` (R4-A), `osm`/`poi` (R4-B), `<source>`/`place` where source ∈ {`google-maps`, `osm`, `foody`, `manual`} (R4-D).
- Synthetic URLs for records with no real URL: `vn://<provider>/<key>` (url_key() handles custom schemes).

## §3 `admin_units.py` (R4-A)

- `V1_API = "https://provinces.open-api.vn/api/v1/"`, `V2_API = "https://provinces.open-api.vn/api/v2/"` (v2 = post-2025-merger: 34 provinces → wards, districts abolished; v1 = legacy 3-level, 63 provinces).
- `fetch_all(version: int = 2, *, timeout: float = 30.0) -> list[dict]` — GET `{API}?depth=2` → parsed JSON list. Raise `VnGeoError` on failure. (v2 items: `{name, code, division_type, codename, phone_code, wards:[{name, code, division_type, codename}]}`.)
- `normalize(payload: list[dict], version: int) -> list[dict]` — flatten to records:
  - province: `{"level":"province","code":int,"name":str,"division_type":str,"codename":str,"version":int}`
  - ward (v2): `{"level":"ward","code":int,"name":str,"division_type":str,"codename":str,"province_code":int,"province_name":str,"version":int}`
  - v1: also district level; ward records carry `district_code`, `district_name`, `province_code`, `province_name`.
- `records_to_documents(records) -> list[dict]` — doc kwargs for `ingest_document`:
  - url: `f"vn://provinces-api/v{version}/{level}/{code}"`, title: name,
  - text: `f"{name} — {division_type}, Việt Nam. Mã {code}."` + (for ward) `f" Thuộc {province_name}."` + codename (FTS-friendly; diacritics fold automatically),
  - provider `"provinces-api"`, format `"admin"`, meta: the full record.
- `ingest(store, records) -> dict` — ingest all, return `{"documents": n, "provinces": n, "wards": n, "districts": n}` (districts only v1).
- `lookup(store, query: str, *, limit: int = 20) -> list[dict]` — FTS search; keep only `provider == "provinces-api"`; return `{"name","level","code","province_name","url","snippet"}`.
- CLI: `fetch --version {1,2} --out data/admin_units_v{n}.json` · `ingest --db DB --file data/...` (version read from file records) · `lookup "Yên Dũng" --db DB [--limit 20] [--json]`.
- Fixtures: trim from ONE real fetch — v2 fixture MUST include Bắc Ninh (with ward Yên Dũng if present) + 1-2 other provinces, ≤10 wards each; v1 fixture small (1 province, 1 district, few wards). Store as JSON files.
- Evidence: full v2 fetch to `data/admin_units_v2.json` (real run) → ingest into `C:/Users/atton/AppData/Local/hermes/cache/scratch/r4a.db` → `lookup "Yên Dũng"` and `lookup "Nham Biền"` showing hits. Report counts (expect ~34 provinces, ~3.3k wards).

## §4 `overpass_poi.py` (R4-B)

- `MIRRORS = ["https://overpass-api.de/api/interpreter", "https://overpass.kumi.systems/api/interpreter"]`.
- `CATEGORIES: dict[str, list[str]]` — at least: `food`=[restaurant, cafe, fast_food], `shops`=[supermarket, convenience_store, bakery], `services`=[bank, atm, pharmacy, hospital], `fuel`=[fuel], `stay`=[hotel, guest_house], `education`=[school]. Values are OSM `amenity`/`shop` values (use `nwr["amenity"~"^(...)$"]` + `nwr["shop"~"^(...)$"]` pattern).
- `build_query(south, west, north, east, categories: list[str]) -> str` — Overpass QL: `[out:json][timeout:60];( ... );out center tags;`. Unknown category → `VnGeoError`.
- `fetch(query: str, *, mirrors: list[str] | None = None, timeout: float = 60.0) -> dict` — POST body `data=<query>` (urlencode); mirror fallback on HTTPError/URLError/timeout (429/504 must advance to next mirror); all fail → `VnGeoError` listing errors. Return parsed JSON.
- `normalize(payload: dict) -> list[dict]` — from `elements` (node/way/relation with `center`): `{"osm_type":"node|way|relation","osm_id":int,"lat":float,"lon":float,"name":str|None,"category":str,"tags":{phone,website,opening_hours,cuisine,addr:street,addr:city,"addr:ward" if present}}`. SKIP elements without `name` (not searchable).
- `records_to_documents(records) -> list[dict]` — url `https://www.openstreetmap.org/{osm_type}/{osm_id}`, title=name, text `f"{name} — {category}. {addr parts if any}."`, provider `"osm"`, format `"poi"`, meta=record.
- `ingest(store, records) -> dict` `{"documents": n, "by_category": {...}}`; `save_jsonl(records, path)` / `load_jsonl(path)`.
- CLI: `fetch --bbox S,W,N,E --categories food,shops --out data/poi.jsonl` · `ingest --db DB --file data/poi.jsonl`.
- Fixtures: real small Overpass response (trim to ≤5 elements, keep one way with `center`) → JSON.
- Evidence: live fetch bbox around Yên Dũng `21.17,106.20,21.24,106.30` categories `food` → jsonl → ingest into `.../scratch/r4b.db` → run `python -m searchstore --db ... search "phở"` (searchstore CLI) and show hits (may be 0 — that's the known thin-OSM reality; report honestly what it returns).

## §5 `places.py` (R4-D)

- Place record schema (JSONL): `{"source": str, "source_id": str, "name": str, "address": str|None, "lat": float|None, "lon": float|None, "rating": float|None, "review_count": int|None, "category": str|None, "hours": str|None, "phone": str|None, "website": str|None, "extra": dict, "scanned_at": iso8601 str}`.
- `parse_rating_label(label: str) -> tuple[float|None, int|None]` — parse Google Maps VN aria labels like `"4,8 sao 24 bài đánh giá"` → `(4.8, 24)`; tolerate English (`"4.8 stars 24 reviews"`), missing count, `"Chưa có bài đánh giá"` → `(None, 0)`.
- `place_key(record) -> str` — `source_id` if non-empty else `f"{name}|{lat:.5f},{lon:.5f}"` (name lowercased, whitespace collapsed).
- `load_scan_jsonl(path) -> list[dict]` / `save_scan_jsonl(records, path)` — records in the schema above.
- `save_places(store, records, *, source: str | None = None) -> dict` — for each record: url = real listing URL if `extra["url"]` else `vn://{source}/{place_key}`; text = `f"{name}. {category}. {address}."` + hours; provider = source; format `"place"`; meta = full record. Count `{"new": n, "updated": n, "unchanged": n}` — new = no prior doc for url_key, updated = prior exists with different content (searchstore creates a new version), unchanged = same content. After the batch: `store.record_event("places_saved", {"source": src, "count": len(records), "keys": [place_key(r) for r in records]})`.
- `query_places(store, *, text: str | None = None, area: str | None = None, category: str | None = None, min_rating: float | None = None, limit: int = 20) -> list[dict]` — FTS `text` when given (search + filter provider-of-place sources), then filter by `area` (substring match on address/meta province/ward fields), `category` (substring, case/diacritics-insensitive), `min_rating`; return `{"name","source","address","lat","lon","rating","review_count","category","url","scanned_at"}` sorted by rating desc (None last).
- `diff(store, *, source: str | None = None) -> dict` — `{"added": [keys], "removed": [keys], "changed": [{"key","name","changes": {field: [old, new]}}]}`: added/removed from the last two `places_saved` events (same source); changed = docs with ≥2 versions (compare latest vs previous on name/rating/review_count/hours/address). No events yet → empty result, no crash.
- CLI: `save --db DB --file scan.jsonl --source google-maps` · `query --db DB [--text phở] [--area "Yên Dũng"] [--category "quán ăn"] [--min-rating 4] [--limit 20] [--json]` · `diff --db DB [--source google-maps] [--json]`.
- Fixtures: `scan_a.jsonl` (5 rows, VN labels incl. `4,8 sao 24 bài đánh giá`, one row without rating) + reuse in tests; a second fixture batch for diff tests (can be built inline in tests via tmp files).
- Evidence: scratch db `.../scratch/r4d.db`: save fixture batch A → query `--area "Yên Dũng"` and `--min-rating 4` outputs; save batch B (one place rating changed, one new place) → `diff` shows 1 added + 1 changed. Paste real outputs in report.
