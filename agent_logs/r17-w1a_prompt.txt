DELIVERABLE 1 — gateway/providers/__init__.py:
  - Module docstring referencing analysis/r17-interfaces.md §1 (frozen v1.0).
  - class Provider(Protocol) with @runtime_checkable:
      name: str
      capabilities: frozenset[str]          # subset of {"search", "extract"}
      def search(self, query: str, *, max_results: int = 10) -> list[SearchItem]: ...
      def extract(self, urls: list[str], *, char_limit: int = 15000) -> list[ExtractItem]: ...
    (import SearchItem/ExtractItem from gateway.protocols — REUSE, do not redefine)
  - class ProviderError(Exception): __init__(self, name: str, detail: str) stores self.name/self.detail;
    __str__ returns f"provider {name!r}: {detail}".
  - PROVIDERS: dict[str, Callable[[], Provider]] = {}   # name -> factory; intentionally EMPTY in W1A
    (W2 registers exa/parallel/jina/v2ex/bilibili/youtube/rss later)
  - def get_provider(name: str) -> Provider:
      normalize name (str(name or "").strip()); if in PROVIDERS -> return PROVIDERS[name]();
      else raise ProviderError(name, "unknown provider")   # str(exc) must contain "unknown provider"
  - def build_registry(config: GatewayConfig) -> list[Provider]:
      if not config.providers_enabled: return []
      for n in config.enabled_providers(): if n in PROVIDERS: append PROVIDERS[n](); stop at config.providers_max
      unknown names are skipped silently (per-source isolation philosophy); order = config order (stable).
  - __all__ = ["PROVIDERS", "Provider", "ProviderError", "build_registry", "get_provider"]
  - Import GatewayConfig as: from gateway.config import GatewayConfig (config does not import providers — no cycle).
