1) gateway/providers/fanout.py:
   class ProviderFanoutBackend — SearchBackend adapter over a provider registry:
     name = "providers"
     __init__(self, providers: list[Provider], *, warnings: list[str])
     search(self, query, *, max_results=10) -> list[SearchItem]:
       - call ONLY providers with "search" in provider.capabilities (skip others SILENTLY — no warning);
       - per provider: try provider.search(query, max_results=max_results); on ANY exception append
         f"provider {p.name} failed: {exc}" to self._warnings and CONTINUE;
       - merge items in provider order; set position = i+1; return the merged list.
     extract(self, urls, *, char_limit=15000) -> list[ExtractItem]:
       - v1: return [ExtractItem(url=u, error="provider extract not supported (v1)") for u in urls]
         (never called by the engine in v1 — protocol completeness only)
     ping(self) -> {"ok": True, "detail": f"provider fan-out ({len(self._providers)} providers)"}
   Note: warnings list.append is thread-safe (GIL) — append directly, no locks.

2) gateway/core/engine.py — ONE call-site + ONE new method:
   a) Call-site: INSIDE the existing `if mode == "deep" and not deadline_passed():` block, immediately
      AFTER the `if ultra_n == 0: for q in sub_queries: ...` serial loop (sub_queries is in scope there),

        if getattr(self.config, "providers_enabled", False) and not deadline_passed():

   b) New method _provider_fanout(self, query, sub_queries, deadline_passed, warnings) -> list[SearchItem]:
      - targets = _dedupe_texts([query] + list(sub_queries))   # probe query + subs, deduped, keep order
      - registry = build_registry(self.config, warnings=warnings); if not registry or not targets: return []
        (warnings param added in W1A reviewfix — surfaces failed provider factories)
      - pool = BackendPool(factory=lambda: ProviderFanoutBackend(registry, warnings=warnings),
                           size=int(getattr(self.config, "pool_size", 4) or 4), deadline_passed=deadline_passed)
        (per-request pool, same lifecycle as _get_ultra_pool's owned pool — its workers build provider
         adapters, NOT gateway backends, so the ultra/backend pool instance cannot be shared; the EXISTING
         BackendPool machinery IS reused)
      - try: results = pool.map_search(list(targets), max_results=self.config.fast_max_results)
        finally: pool.close()
      - for each (q, items, err): if err not in ("", "deadline"): warnings.append(f"provider fan-out failed for {q!r}: {err}")
      - return concatenation of non-None item groups in input order.
      - The WHOLE body is wrapped so ANY unexpected failure -> warnings.append(...) + return [] (isolation:
        provider fan-out must never fail the request).
   c) providers_enabled=false (default): call-site condition false -> byte-identical behavior (regression gate).
